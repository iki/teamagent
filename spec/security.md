# Security, execution boundaries, and evidence

The core rule is to keep user intent and authorization separate from model output, retrieved content, skill instructions, and tool results. The harness must enforce resource and action limits outside the language model. Scanners provide evidence; they do not replace runtime isolation or authenticated policy checks.

This is an architectural threat analysis, not a penetration test or a claim that the reviewed projects are secure. Recommendations below are grounded in specific source mechanisms and their stated trust assumptions.

## Adapter authority and credential findings reviewed 2026-10-28

The [OpenClaude Gemini-auth review](projects/ai-agents--claude.fork.openclaude.md) distinguishes component-safe endpoint construction from account binding. Credential-file presence and cached ADC results do not establish current authentication, and selected environment hints do not isolate an SDK's ambient credential chain. This is the same canonical repository/revision as the separate OpenClaude tool-pool report, with a different inspected scope; it is not independent corroboration.

[LiteLLM](projects/ai-agents-proxy--litellm.md), reviewed at `0a1dbc0fb4f6b52aec97700dddb457adf91d1cbd`, clears selected server-owned provider credentials/configuration when a client changes the endpoint and blocks unresolved identity references there. That provider-specific boundary does not establish every fallback's authority. [Agentic Bug Hunter](projects/ai-agents--agentic-bug-hunter.md), reviewed at `16dabf0cea8a43ad9d42733283e0fd8ed74313c0`, keeps values out of some summaries but still exposes credential material through malformed-input errors, partial redaction, process arguments and child environment helpers. Bind credentials to approved destinations and audit every propagation surface, not only logs.

[Warp's MCP OAuth adapter](projects/ai-agents--warp.md) preserves refresh tokens omitted by a refresh response, but an in-memory save plus queued persistence is not a durable write acknowledgement. Its local clear operation also does not prove stored-token deletion. [Paperclip's approval page](projects/ai-agents--paperclip.md) explicitly describes broad board access while retaining the challenge token in URLs and navigation state; a displayed organization is audit context, not necessarily the grant scope. Require explicit expiry, consumption, persistence and deletion outcomes at the host boundary.

[ZeroClaw](projects/ai-agents--zeroclaw.md) separates declared egress destinations from saved instance grants and refuses to extend existing grants during binding. Its typed artifact projection still needs path, identity and access validation. [Zero](projects/ai-agents--zero.md) records an unsandboxed direct-launch path explicitly and separates retained capture from emitted output; display redaction alone does not establish spill-file privacy. These are scoped source findings, not tested platform guarantees.

## Additional source findings reviewed 2026-10-28

The [Antfu attachment fallback](projects/ai-skills--bundle.antfu.md) illustrates why avoiding log output is insufficient credential protection: a bearer header supplied as a process argument remains exposed through that interface. Trusted upload adapters need a protected credential channel, bounded bytes/time, structural response validation and explicit destination authorization. Treat the new observability entries in [Awesome OpenRouter](projects/ai-info--awesome-openrouter.md) as discovery leads; a catalog claim to trace every prompt does not establish acceptable retention, tenant isolation or redaction.

[Bifrost](projects/ai-agents-proxy--bifrost.md) binds connection pools to policy fingerprints and closes idle pools when configuration changes; call-site enforcement, existing in-flight requests and separate passthrough routes still need independent review. [OpenEval](projects/ai-eval--openeval.md) pins an allowed public IPv4 destination and checks TLS SNI, but the reviewed parser leaves a complete oversized-header case outside its size check and does not establish container-wide egress enforcement. [Mantis](projects/ai-security--mantis.md) supplies mocked isolation-creation tests, which should accompany real runtime acceptance checks.

The [minimal harness and guard review](analyses/unreviewed/ai-info--best-of-agent-harnesses.md) found shell-prefix approval, full output capture before clipping, non-atomic transcript writes and fail-open guard paths. These are educational/advisory mechanisms, not production authorization, isolation or spend controls. [Codex Security's workflow](projects/ai-security--codex-security.md) usefully separates patch identity, consequence, evidence strength and advisory recommendations; the model's recommendation never grants merge authority. [REA's protocol review](analyses/unreviewed/ai-security--rea.md) similarly distinguishes validated shapes and cleanup acknowledgements from independently demonstrated runtime behavior.

[OpenSandbox](projects/ai-agents-sandbox--opensandbox.md), [Optio](projects/ai-agents-swarm--optio.md) and [Shadowbroker](projects/ai-agents-swarm--shadowbroker.md) supply useful credential-transport and origin/locality fixtures. Cookie or subprotocol transport alone does not establish token lifetime, duplicate-credential rejection, per-message resource authorization or revocation. Reject policy-required proxy configuration failures rather than silently taking the direct route illustrated in [CodexBar Win](projects/ai-agents-tokens--codexbar-win.md). Retained request bodies, query values and raw errors in [LLM Observer](projects/ai-agents-proxy--llm-observer-proxy-go.md) and other diagnostic paths need explicit privacy controls.

[E2B](projects/ai-agents-sandbox--e2b.md), [AgentEnv](projects/ai-agents-sandbox--agentenv.md) and [Anthropic's sandbox runtime](projects/ai-agents-sandbox--anthropic-sandbox-runtime.md) reinforce separate limits for queues, open connections, waiting and in-flight cancellation. Error-path rollback is weaker than cancellation-safe ownership. [Cloudflare Computer's stream parser](projects/ai-agents-sandbox--cloudflare-computer.md) and the reviewed OpenRouter SDK type declarations require semantic validation before dispatch; shape descriptions and casts are not enforcement. [OSV.dev's storage adapter](projects/ai-security--osv.dev.md) shows why create-only writes still need replay-safe input streams and explicit ownership of shared clients.

[AISOC's proxy helper](projects/ai-security--aisoc.md) checks the immediate peer before accepting forwarded addresses; identity transport, connector credentials and downstream tenant enforcement remain separate responsibilities. [CodeQL's Go registry helper](projects/ai-security--codeql.md) shows that certificate-file creation failures, inherited environment and direct-network fallbacks require explicit policy handling. [Awesome LLM Apps' Excaliflow server](projects/ai-info--awesome-llm-apps.md) illustrates the difference between lexical path containment and resolved filesystem containment, and between a localhost URL in documentation and an explicitly loopback-bound listener.

[TypeSafe's Python SDK](projects/ai-skills--typesafe-sdk-python.md) reference-counts asset scopes, but a shared client's attachments are not automatically isolated per async task. Its lenient JSON helper, configuration and multipart builder still need strict transport schemas, URL policy and byte bounds. [Ontos' adapters](projects/ai-spec--techsio.ontos.md) illustrate scoped service ownership and transaction-bound publication, while multi-statement test cleanup still needs an isolated destination and a partial-failure contract. These patterns do not select dependencies or alter Teamagent's adopted stack.

The [Awesome MCP Servers delta](projects/ai-info--awesome-mcp-servers.md) is discovery evidence only. Catalog descriptions of signed receipts, read-only tools, logged-in browsers, payment caps or approval prompts do not establish enforcement. A byte-identical response for two principals is not sufficient evidence of unauthorized disclosure; a typed classifier can be wrong even without generating prose. Before adapting a listed service, inspect the exact implementation, principal/resource binding, transport, executable package identity, cancellation and replay behavior. Never turn mutable installation snippets, catalog labels or a model-supplied confirmation field into authorization.

## Boundaries that must remain explicit

| Boundary | Main failure modes | Required control |
|---|---|---|
| User/channel → task | Spoofed identity, replay, channel cross-talk | Authenticated principal, deduplicated event ID, tenant/task mapping |
| Resource → knowledge base | Prompt injection, poisoned memory, parser attacks, private URL fetch | Staging, provenance, parser limits, URL policy, data/instruction separation |
| Skill/plugin → runtime | Malicious instructions, dependency execution, excess permissions | Immutable package, inspection ledger, capability grant, sandbox |
| Agent → tool action | Unintended side effect, argument injection, repeated execution | Typed arguments, server policy, idempotency/reconciliation, audit |
| Worker → host/network | Filesystem escape, credential leakage, lateral movement | Enforced sandbox, scoped mounts, mediated egress, secret broker |
| Result → user/client | Executable generated UI, unsafe links, misleading completion | Output validation, trusted renderer, explicit partial/failed states |
| Evaluation → evolution | Reward hacking, leakage, unreviewed promotion | Held-out tasks, immutable evidence, signed/versioned promotion, rollback |

Import and memory concerns are developed in [import-generation](import-generation.md) and [memory](memory.md); skill lifecycle in [skills](skills.md); channel identity in [channels](channels.md).

## Execution classes

| Class | Intended work | Reference and limitation |
|---|---|---|
| Pure data operation | Parsing a bounded schema, ranking, safe transformations | Minimal trusted code; no external side effects |
| Interpreted shell/tool environment | Bounded text/data manipulation over staged files | [just-bash report](projects/ai-agents-sandbox--just-bash.md) · [GitHub](https://github.com/vercel-labs/just-bash): host hooks, runtime, dependencies are trusted |
| Restricted host process | Local coding agent in a selected workspace | [sandbox-runtime report](projects/ai-agents-sandbox--anthropic-sandbox-runtime.md) · [GitHub](https://github.com/anthropics/sandbox-runtime): verify platform setup and fail-closed enforcement |
| Disposable container/VM worker | Builds, parsers, native rendering, untrusted dependencies | [OpenSandbox report](projects/ai-agents-sandbox--opensandbox.md) · [GitHub](https://github.com/alibaba/OpenSandbox): strength depends on runtime/host configuration |
| Hosted sandbox adapter | User-selected remote execution | [E2B report](projects/ai-agents-sandbox--e2b.md) · [GitHub](https://github.com/e2b-dev/e2b): SDK behavior does not prove complete backend isolation |
| Browser/device session | UI-driven task or authorized test | [Artemis report](projects/ai-operate--artemis.md) · [GitHub](https://github.com/google/artemis): exclusive device ownership and state-aware retry |

Do not collapse these into one boolean called “sandboxed.” A worker advertises independently verified read/write, network, process, device, credential, and resource capabilities. A task chooses a class from its inputs and required operations. Unsupported restrictions cause refusal or rerouting, not an unrestricted fallback.

The inspected [sandbox-runtime Windows wrapper](projects/ai-agents-sandbox--anthropic-sandbox-runtime.md) ([GitHub](https://github.com/anthropics/sandbox-runtime)) includes a dedicated-user/WFP/ACL design and verification errors. That supports a Windows implementation path, but installation, enforcement, cancellation, cleanup, and machine-policy interactions still require actual host tests. [just-bash's threat model](projects/ai-agents-sandbox--just-bash.md) ([GitHub](https://github.com/vercel-labs/just-bash)) explicitly excludes malicious host hooks and compromised dependencies from its runtime protection.

## Authorization and credentials

Grant capabilities to a task principal with scope, expiry, and constraints. A capability should identify operation, target resources, account, allowed destination, maximum spend or resource budget where applicable, and whether a new user decision is required. The policy engine checks it at execution time; the model cannot extend it by generating a different prompt.

Store secrets in a vault/keychain and pass references through prompts and traces. Inject short-lived scoped credentials only into the adapter that needs them. Masking a string in logs is not sufficient if the entire worker can read unrelated credential files. Do not copy subscription tokens from discovered agents into a universal gateway; follow the supported route described in [models](models.md).

[Bifrost's per-call MCP credential resolution](projects/ai-agents-proxy--bifrost.md) ([GitHub](https://github.com/maximhq/bifrost)) and [OpenSandbox's credential/egress validation dependencies](projects/ai-agents-sandbox--opensandbox.md) ([GitHub](https://github.com/alibaba/OpenSandbox)) are useful mechanisms, but both remain sensitive trusted services. Validate tenant separation and redact headers/body fields before tracing.

## Untrusted content and memory

Every imported document, repository, image OCR result, browser page, and tool response is data with provenance. It can contain instructions describing an attack, a benign tutorial, or malicious commands; none acquires authority merely by being retrieved. Maintain source trust labels and separate evidence excerpts from the task's governing instructions.

Use a staged import pipeline with bounded archive expansion, file count/size limits, MIME detection, symlink rules, parser timeouts, and sanitized derived artifacts. Fetch URLs through an SSRF-aware service which revalidates redirects and resolved addresses. A URL allow-list alone is not a complete defense if DNS or redirects can change the destination. Knowledge-base writes should preserve lineage and permit rollback of a poisoned source and all derived memories.

[SkillSpector's coverage ledger](projects/ai-security--skillspector.md) ([GitHub](https://github.com/NVIDIA/SkillSpector)) supplies useful statuses for malformed archives, unsafe members, unresolved references, opaque content, and exceeded limits. Reuse this approach for import jobs, not only skills. A partial import should say exactly what was omitted.

| Evidence type | Tool and source | Correct interpretation |
|---|---|---|
| Modeled source flow | [CodeQL report](projects/ai-security--codeql.md) · [GitHub](https://github.com/github/codeql) | A query's modeled source-to-sink path; extraction and language models constrain coverage |

| Image/filesystem/SBOM | [Trivy report](projects/ai-security--trivy.md) · [GitHub](https://github.com/aquasecurity/trivy) | Findings on the actual artifact digest and selected scanner modes |
| Skill/plugin instruction and code | [SkillSpector report](projects/ai-security--skillspector.md) · [GitHub](https://github.com/NVIDIA/SkillSpector) | Static/semantic evidence plus explicit incomplete work |
| Installed environment and behavior | [ClawSecCheck report](projects/ai-security--clawseccheck.md) · [GitHub](https://github.com/gl0di/clawseccheck) | Layer/phase observations; pending judgment is not a clean pass |

Avoid one aggregate score that hides a critical finding behind many passing checks. A normalized finding record needs target digest, scanner/rule version, source span, category, severity, confidence, evidence, coverage, database/model timestamp, suppression, owner, and expiration. Distinguish vulnerability presence, reachable behavior, and demonstrated exploitability. Missing credentials, skipped analyzers, unavailable tools, and exceeded deadlines remain unknown/incomplete states.

## Safe side effects and retries

For file edits, use task workspaces, exact diffs, and conflict-aware promotion. For external actions, allocate an idempotency key where supported; otherwise inspect resulting state before retrying. Persist intent, authorization, dispatch, acknowledgement, and observed result separately. An interrupted connection is not proof that the action did not happen.

Streaming inference makes this particularly important: [LiteLLM's generated-content detection](projects/ai-agents-proxy--litellm.md) ([GitHub](https://github.com/BerriAI/litellm)) and [Bifrost's stream handling](projects/ai-agents-proxy--bifrost.md) ([GitHub](https://github.com/maximhq/bifrost)) are mechanisms to study, but the harness must retain responsibility for tool-side effect deduplication. UI/device actions from [Artemis](projects/ai-operate--artemis.md) ([GitHub](https://github.com/google/artemis)) often require state reconciliation because a tap has no transactional acknowledgement.

## Generated output and capability-limited UI

Use trusted renderers and schemas for generated interactive artifacts. [A2UI](projects/ai-gen--a2ui.md) ([GitHub](https://github.com/google/A2UI)) requires explicit strict validator configuration in the inspected path; [json-render](projects/ai-gen--json-render.md) ([GitHub](https://github.com/vercel-labs/json-render)) checks structural integrity but does not replace action authorization. Validate URLs and binds independently of component names.

Render arbitrary generated HTML, imported documents, media, and native code inside the appropriate worker. The [HyperFrames path checks](projects/ai-gen--hyperframes.md) ([GitHub](https://github.com/heygen-com/hyperframes)) and [VoiceStudio base-path contract](projects/ai-media--voicestudio.md) ([GitHub](https://github.com/debpalash/VoiceStudio)) are useful boundary examples, not proof that all browser/codec/engine inputs are safe.

## Evolution and release gates

Skill, prompt, router, parser, and model changes should enter an evaluation branch with immutable inputs and a held-out task set. Promote only when required correctness/security constraints pass and the intended benefit is observed within uncertainty bounds. Retain the previous version, record who or what approved promotion, and support immediate rollback. Self-improvement must not grant the candidate permission to modify its own evaluation criteria.

[ClawSecCheck's honest degradation states](projects/ai-security--clawseccheck.md) ([GitHub](https://github.com/gl0di/clawseccheck)) and [SkillSpector's inspection ledger](projects/ai-security--skillspector.md) ([GitHub](https://github.com/NVIDIA/SkillSpector)) should inform the release evidence format. [OBLITERATUS](projects/ai-model-edit--obliteratus.md) ([GitHub](https://github.com/elder-plinius/OBLITERATUS)) belongs outside ordinary production evolution; model intervention and refusal removal are not established proxies for harness usefulness.

## Required verification before deployment

Verify tenant/workspace separation, forged channel events, path traversal/symlinks, archive bombs, redirect/DNS private-address fetches, secret leakage through errors and media, unauthorized tool invocations, duplicate side effects after retry, cancellation/reaping, stale approval after artifact mutation, and incomplete-scan reporting. Use malicious fixtures in isolated test identities rather than real accounts. Measure false positives, missed known cases, escaped grants, and recovery time; publish limitations and coverage alongside the result. The target is a recoverable, observable system with enforced boundaries, not an unsupported claim of universal prompt-injection immunity.

## Media training and recovery authority

The [media policy contract](media-training.md) and [runtime contract](media-runtime.md) apply before ranking and again before content upload, including voice enrollment. General/shared model improvement is distinct from the requested private clone. Unknown, stale or mismatched policy is blocked. A known training-permitted route requires the invocation's explicit `--allow-training`; backend/model overrides, stored priorities and plan JSON cannot grant it. This option never changes provider sharing settings. Scoped documentary exclusions require current account/key binding; user assertions remain assertions, and authentication alone proves no exclusion.

Backend lists and plans are passive. `media diagnose` performs explicit authenticated metadata requests. Voice consent, retention, cloud egress, commercial rights and training exclusion remain separate decisions. Local inference requires trusted provisioned resources; Python socket restrictions are not an OS firewall.

HeyGen mutations journal an encrypted receipt before submission. Responses preserve bounded redacted HTTP evidence and absent IDs as null. A completed artifact reference is encrypted before URL validation/download; public output discloses only a safe origin/path summary. Download recovery uses the reviewed exact HTTPS origin/path allowlist, no authorization or cookies, no redirects, bounded bytes/time, WAV integrity checks and atomic exclusive publication. It cannot synthesize again. Uncertain attempts require reconciliation; new filenames/keys do not authorize automatic retries. See the runtime contract for the narrower coverage of other adapters and expired URL recovery limits.

## Follow-up source review: 2026-10-28 — effective controls and incomplete evidence

Stop controls need distinct states for deliberately unconfigured, released, engaged and unreadable. [AiSOC](https://github.com/beenuar/AiSOC) ([review](projects/ai-security--aisoc.md)) fails closed on a configured control-read error, but its connection timeout does not independently bound the query/close phases, and tenant-only cache identity does not reflect a changed control source. A Teamagent control must carry effective scope, observation time and control-generation identity; invalidate cached permission when that identity changes. The review of this reader does not prove enforcement across every dispatch path.

Suppression and incomplete comparison coverage belong beside findings. [OSV Scanner](https://github.com/google/osv-scanner) ([review](projects/ai-security--osv-scanner.md)) exposes override usage and scope, with mode-specific treatment of license-only rules. [OSV.dev](https://github.com/google/osv.dev) ([review](projects/ai-security--osv.dev.md)) drops shadow comparisons when capacity is full and uses cooperative deadlines; a comparison score therefore needs admitted/dropped coverage. The [Trivy](https://github.com/aquasecurity/trivy) ([review](projects/ai-security--trivy.md)) delta is a dependency revision, which must not become a claim of improved detection without the corresponding advisory and validation evidence. [Codex Security](https://github.com/openai/codex-security) ([review](projects/ai-security--codex-security.md)) validates a ServiceNow template and clips exported narratives; retain original findings and distinguish recorded reproduction steps from demonstrated reproduction. Its output preflight alone is not exclusive atomic publication.

Diagnostic handoffs require authority checks and recoverable state independently of their prompts. [Awesome Copilot](https://github.com/github/awesome-copilot) ([review](projects/ai-skills--agent-copilot.md)) checks local request identity and records pending dispatch, but redaction remains heuristic and process-local acknowledgement does not prove session creation. Bound server body time, buffered responses and durable pending-state retention. [Trail of Bits skills](https://github.com/trailofbits/skills) ([review](projects/ai-skills--security.trailofbits.md)) now resolve resources from the exact loaded skill instead of searching the audited tree; enforce that relationship with containment and trusted hashes, beyond the instructional test inspected upstream.

Passive guidance remains separate from execution authority. [REA](https://github.com/morluto/rea) ([review](analyses/unreviewed/ai-security--rea.md)) validates list/render requests and filters the available prompt contracts by tool family; rendering is neither running the analysis nor granting a capability. [Vercel's temporary-deployment skill](https://github.com/vercel-labs/agent-skills) ([review](projects/ai-skills--deploy-vercel.md)) describes an external publication even when no account login is used. Keep content authorization, confidential claim references, deployment acknowledgement and functional verification distinct. These are scoped static findings, with no upstream execution or live-service verification in this review.

## Source synthesis: 2026-11-01 — independent authority and complete evidence

The reviewed mechanisms below are threat-model and acceptance-test inputs, not a security certification or proof of their deployed enforcement. Teamagent's implemented gates remain documented in the [harness](harness.md) and [media runtime](media-runtime.md); static upstream review does not add an integration or authorize a new effect.

**Revalidate the actual principal and operation.** [Cindy](https://github.com/makecindy/cindy) ([review](analyses/unreviewed/ai-agents--cindy.md)) separates channel authority from content; [Oh My Hermes](https://github.com/rlaope/oh-my-hermes) ([review](analyses/unreviewed/ai-agents--oh-my-hermes.md)) binds consent to exact scope/run/policy, while [MLflow](https://github.com/mlflow/mlflow) ([review](projects/ai-agents--mlflow.md)) applies resource scope before retrieval. [Bifrost](https://github.com/maximhq/bifrost) ([review](projects/ai-agents-proxy--bifrost.md)) adds live refresh-grant checks and [LangWatch](https://github.com/langwatch/langwatch) ([review](projects/ai-eval--langwatch.md)) binds delegated credentials to issuing sessions. [AISOC](https://github.com/beenuar/AiSOC) ([review](projects/ai-security--aisoc.md)) illustrates context that tightens a deterministic baseline without converting unknown context into permission. Cached consent, workspace membership, model confidence and first-party adapter identity are not interchangeable grants.

**Minimize sensitive representations, not only log fields.** [CLIProxyAPI](https://github.com/router-for-me/CLIProxyAPI) ([review](projects/ai-agents-proxy--cli-proxy-api.md)) negotiates omission of auth-plugin bodies but retains headers/query metadata. [OpenSandbox](https://github.com/alibaba/OpenSandbox) ([review](projects/ai-agents-sandbox--opensandbox.md)) distinguishes opaque credential markers from rendered secrets; [OpenClaude](https://github.com/Gitlawb/openclaude) ([review](projects/ai-agents--openclaude.md)) exposes process-environment ownership concerns. [Agent Governance Toolkit](https://github.com/microsoft/agent-governance-toolkit) ([review](projects/ai-agents-sandbox--agent-governance-toolkit.md)) shows why hashing a guessable query does not ensure confidentiality. [Prompts.chat](https://github.com/f/prompts.chat) ([review](projects/ai-prompts--prompts.chat.md)) and [Claude Code Kit](https://github.com/padak/claude-code-kit) ([review](projects/ai-skills--xx-2602-bundle-claude.padak.md)) motivate protected credential/state storage instead of query strings or URL fragments. Bound retention and diagnostic fields independently of transport success.

**Validate destinations and policy-bearing files at the effect boundary.** The DNS-error convenience branch in [Skillware](https://github.com/ARPAHLS/skillware) ([review](projects/ai-agents-skills--manage.skillware.md)) is not successful resolution evidence, and the scheme check in [A2UI](https://github.com/google/A2UI) ([review](projects/ai-gen--a2ui.md)) is not an origin/path allowlist. [Spec Kit](https://github.com/github/spec-kit) ([review](projects/ai-spec--spec-kit.md)) rejects linked integration state independently of ordinary file policy; the lexical virtual paths in [Quarkdown](https://github.com/iamgio/quarkdown) ([review](projects/ai-gen--quarkdown.md)) do not establish physical containment. [Paseo](https://github.com/getpaseo/paseo) ([review](projects/ai-agents--paseo.md)) treats hook proposals and ignored-secret copying as separate concerns. Bind authorization to the final resolved resource and preserve unknown/error states; inspect race and platform behavior separately from preflight validation.

**Keep execution evidence separate from permission and cleanup.** [OpenInterpreter](https://github.com/openinterpreter/openinterpreter) ([review](projects/ai-agents--openinterpreter.md)) separates upload grant, transfer and finalization; [HarnessRouter](https://github.com/HarnessRouter/harnessrouter) ([review](projects/ai-agents--harnessrouter.md)) reinforces reconciliation before uncertain replay. [AgentEnv](https://github.com/kvcache-ai/AgentEnv) ([review](projects/ai-agents-sandbox--agentenv.md)) distinguishes transport shutdown from store fencing, and [ZeroClaw](https://github.com/zeroclaw-labs/zeroclaw) ([review](projects/ai-agents--zeroclaw.md)) requires owned dead leases for stage recovery. [Experiential](https://github.com/experientiallabs/experiential) ([review](analyses/unreviewed/ai-agents-proxy--experiential.md)) retains policy/evaluation identity independently of model selection. A finished stream, expired lease, missing result or policy manifest cannot prove that an external effect did not occur or that all descendants stopped.

**Do not turn inspection gaps into clean results.** [SkillSpector](https://github.com/NVIDIA/SkillSpector) ([review](projects/ai-security--skillspector.md)), [ClawSecCheck](https://github.com/gl0di/clawseccheck) ([review](projects/ai-security--clawseccheck.md)) and [REA](https://github.com/morluto/rea) ([review](analyses/unreviewed/ai-security--rea.md)) distinguish incomplete inspection and bounded estimates from complete measurements. [OSV Scanner](https://github.com/google/osv-scanner) ([review](projects/ai-security--osv-scanner.md)) keeps suppression provenance/expiry, and [Trivy](https://github.com/aquasecurity/trivy) ([review](projects/ai-security--trivy.md)) scopes successful and failed import caching to a source generation. [Better Stack's Claude plugin](https://github.com/betterstackhq/claude-plugin) ([review](analyses/unreviewed/ai-skills--log.betterstack.claude.md)) provides a concrete instruction-authority counterexample: remote setup prose remains untrusted. Preserve findings and unknown coverage through scoring, caching, generated reports and proposed remediation.

## External-update synthesis: 2026-11-01 — preserve authority through adapters

[OpenRig](https://github.com/mvschwarz/openrig) ([review](analyses/unreviewed/ai-agents--openrig.md)) permits in inspected cases where an approver or representable choice is unavailable or a closed reply is ambiguous; an unanswered still-open request remains pending. The permissive fallbacks are not adopted: Teamagent retains unknown/pending authorization and does not execute the sensitive action. [Lean-ctx](https://github.com/yvgude/lean-ctx) ([review](projects/ai-agents-mem--lean-ctx.md)) also distinguishes release policy provenance from debug ambient configuration. Authority must not be replaceable by command-controlled environment or model output.

[MCP Rust](https://github.com/modelcontextprotocol/rust-sdk) ([review](projects/ai-query--mcp-sdk-rust.md)) preserves typed OAuth discovery failures and nested causes. Keep those distinctions while redacting nested URLs/messages at display boundaries; a failed discovery must not authorize an unadvertised server. [Beads](https://github.com/gastownhall/beads) ([review](projects/ai-agents-mem--beads.md)) reinforces nested-error redaction, and [RAGFlow](https://github.com/infiniflow/ragflow) ([review](projects/ai-agents-mem--ragflow.md)) shows why an empty audit sink is not durable evidence. These are scoped committed-source findings, not exploit demonstrations or third-party security attestations.

[AI SOC](https://github.com/beenuar/AiSOC) ([review](projects/ai-security--aisoc.md)) needs dataset/source coverage alongside derived classifications; no match or an unavailable dataset remains unknown. [Codex Security source project](https://github.com/openai/codex-security) ([review](projects/ai-security--codex-security.md)) separates local evidence validity from remote wire-format requirements and optional observers from mandatory integrity checks. [REA](https://github.com/morluto/rea) ([review](analyses/unreviewed/ai-security--rea.md)) stops dependent traversal when cleanup is incomplete, preserving useful partial evidence and the unresolved resource owner. [Open Notebook](https://github.com/lfnovo/open-notebook) ([review](analyses/unreviewed/ai-agents--open-notebook.md)) explicitly permits private/localhost service URLs and can move stored provider keys into process environment. Those convenience choices do not provide request-isolated credentials, public-import destination safety or multi-user authorization. Its single-user design decision and absent-password behavior must remain visible before any team deployment is considered.

Keep first-use trust distinct from broken trust evidence. [uniTerm](https://github.com/ys-ll/uniterm) ([review](analyses/unreviewed/ai-agents-swarm--uniterm.md)) binds one-use host-key exceptions to an exact key, but its inspected lookup-error path can record and accept a new key after trust-store corruption; an upstream fixture expects this recovery. Teamagent should require deliberate recovery rather than silently treating corruption as first use. This is a static finding, not an executed exploit. [Agent Tincan](https://github.com/mvanhorn/agent-tincan) ([review](analyses/unreviewed/ai-agents-swarm--agent-tincan.md)) separately illustrates that redacting an audit note to its byte count does not remove the note from an authorized list response; audit privacy and response audience remain separate checks.

[GitHub Agentic Workflows](https://github.com/github/gh-aw) ([review](analyses/unreviewed/ai-agents-swarm--gh-aw.md)) checks token-producing step placement and redacts keys/values before serializing action receipts. These are useful bounded controls, not a universal credential-flow proof. [Sim](https://github.com/simstudioai/sim) ([review](analyses/unreviewed/ai-agents-swarm--sim.md)) distinguishes operator service URLs from untrusted content-fetch URLs and hands an approved address to its caller; that caller must preserve the address at connection time. Credential scope, egress permission, action consent and provider training policy remain independent gates, with unreviewed transport paths explicitly outside these findings.

The November 1 [goose](https://github.com/aaif-goose/goose) ([review](analyses/unreviewed/ai-agents--goose.md)) inspection distinguishes permission classification from its egress inspector, which logs selected destinations and returns Allow. This is telemetry, not a firewall; destination strings need privacy scrubbing and actual transports need independent enforcement. [AgentScope](https://github.com/agentscope-ai/agentscope) ([review](analyses/unreviewed/ai-agents--agentscope.md)) separately represents owner/resource grants, while its local workspace lifetime is not OS isolation. [Deep Agents](https://github.com/langchain-ai/deepagents) ([review](analyses/unreviewed/ai-agents--deepagents.md)) supplies an execution-boundary exclusion fixture, but the complete permission implementation was not audited; graph wiring alone is insufficient assurance. [MaxKB](https://github.com/1panel-dev/maxkb) ([review](analyses/unreviewed/ai-agents-mem--maxkb.md)) has distinct chat and workflow retrieval authorization paths whose equivalence needs explicit fixtures before embedding or fetching. [Claude How To](https://github.com/luongnv89/claude-howto) ([review](analyses/unreviewed/ai-info--claude-howto.md)) further illustrates why educational hook protocols and a Bash-enabled review role cannot establish host enforcement or read-only operation. These findings add acceptance obligations without importing execution authority.

The November 2 [HyperFrames follow-up](https://github.com/heygen-com/hyperframes) ([review](projects/ai-gen--hyperframes.md#follow-up-source-review--2026-11-02)) resolves `file:` URLs and Windows Git Bash drive paths, including existing absolute files. ## Source addition: 2026-11-02 — explicit floors and audit obligations

[OpenWorker](https://github.com/andrewyng/openworker) ([scoped review](analyses/unreviewed/ai-agents--openworker.md)) separates deterministic deny/human-only decisions from model-eligible approvals and rechecks reviewer/context state. Its dangerous bypass mode deliberately clears several ordinary floors, so a mode label cannot imply uniform authority. The shell/path classifiers and sandbox transports were outside scope; no OS containment claim follows. Audit calls pass tool arguments to a sink and suppress sink errors, which does not establish redaction, durable persistence or fail-closed action receipts. Keep those host obligations independent, and reject non-finite decision probabilities before scoring. These are source-level lessons with no upstream execution, security exploit test or expanded Teamagent authority.
