## Source records and embedding transformations

The model separates knowledge bases and their embedding model/workspace scope from documents, ordered paragraphs and embedding rows linked back to source/document/paragraph IDs. Files retain a SHA-256 field and source relationship; workflow versions have separate history records. These fields support traceability, but do not by themselves establish immutable document-version chains or static-versus-refresh policy. [Models](https://github.com/1panel-dev/maxkb/blob/d8dd35f6cafa7b8ddeda92d60923087724d29d4c/apps/knowledge/models/knowledge.py#L118-L384).

Embedding normalization removes emoji/symbol ranges and collapses whitespace before vector generation; paragraphs can be split into stored or derived chunks. This is a deliberately lossy representation and must remain distinct from the original source text. Batch insertion generates embeddings before a final interruption check. Teamagent should preserve exact originals, parser/chunker/model versions, chunk identity and measured completeness before publishing a new retrieval version. [Normalization and chunking](https://github.com/1panel-dev/maxkb/blob/d8dd35f6cafa7b8ddeda92d60923087724d29d4c/apps/knowledge/vector/base_vector.py#L25-L139), [vector insertion](https://github.com/1panel-dev/maxkb/blob/d8dd35f6cafa7b8ddeda92d60923087724d29d4c/apps/knowledge/vector/pg_vector.py#L45-L110).

## Scoped retrieval and ranking

Query dispatch requires a nonempty knowledge-base list, filters active rows and requested/excluded documents/paragraphs, queries each knowledge base separately, then merges and trims results. The comment ties this shape to per-knowledge-base partial HNSW indexes; no query plan or latency/recall measurement was performed. Embedding, keyword and blend modes delegate to separate SQL templates, which were not read in this scope, so their score formula and index behavior remain unverified. [Query and search dispatch](https://github.com/1panel-dev/maxkb/blob/d8dd35f6cafa7b8ddeda92d60923087724d29d4c/apps/knowledge/vector/pg_vector.py#L149-L349).

The chat pipeline rejects mixed embedding models across selected knowledge bases and resolves a workspace model before query embedding. Its optional chat-user authorization callback is distinct from the workflow node's additional workspace filtering. Both surfaces should receive equivalent authorization fixtures; a workspace ID or filtering helper name is not proof of enforcement. The workflow result retains paragraph records separately from a character-limited concatenated context, while the ordinary pipeline can directly return a high-scoring paragraph. Teamagent should test authorization before embedding or retrieval, report omitted/truncated context, and keep retrieval score separate from answer truth. [Chat retrieval](https://github.com/1panel-dev/maxkb/blob/d8dd35f6cafa7b8ddeda92d60923087724d29d4c/apps/application/chat_pipeline/step/search_dataset_step/impl/base_search_dataset_step.py#L36-L150), [workflow retrieval](https://github.com/1panel-dev/maxkb/blob/d8dd35f6cafa7b8ddeda92d60923087724d29d4c/apps/application/flow/step_node/search_knowledge_node/impl/base_search_knowledge_node.py#L56-L136).

## Jobs, refresh and publication limits

Celery tasks deduplicate work by selected document/paragraph IDs and expose failure state when model loading fails. The knowledge-wide re-embedding path deletes previous embeddings and drops the index before scheduling each document, catching some per-document scheduling exceptions without surfacing an aggregate failure. This is not an atomic version switch; Teamagent should build a complete replacement index alongside the current one and report every omitted job. Queue deduplication is not proof of idempotent provider calls. [Embedding tasks](https://github.com/1panel-dev/maxkb/blob/d8dd35f6cafa7b8ddeda92d60923087724d29d4c/apps/knowledge/task/embedding.py#L25-L137).

Document APIs distinguish web synchronization from vector refresh and apply token authentication plus workspace/knowledge permission decorators. Their delegated implementation was not audited. Teamagent should retain this operation distinction while preserving static articles by default and requiring explicit refresh/validator evidence. [Document API](https://github.com/1panel-dev/maxkb/blob/d8dd35f6cafa7b8ddeda92d60923087724d29d4c/apps/knowledge/views/document.py#L50-L122), [sync versus refresh](https://github.com/1panel-dev/maxkb/blob/d8dd35f6cafa7b8ddeda92d60923087724d29d4c/apps/knowledge/views/document.py#L322-L395).
