## Model-specific assembly and authority

Graph assembly resolves a profile for the main model and each declarative subagent, validates middleware exclusions and verifies that exclusion names actually matched. Tool exclusions are added after custom middleware, with fixtures that deliberately make a scripted model emit an excluded write call and verify the backend file is never created while an allowed call still runs. This is a stronger regression shape than merely checking that a tool schema disappeared. Permissions can be inherited or overridden by a subagent; the actual permission implementation was not covered by the captured compatibility re-export. ## Skill snapshots and disclosure

Skills expose a metadata catalogue and load bodies on demand. Explicit pins append a body snapshot to the conversation, deduplicate requested names and clear the pending pin state. Unknown, unreadable or oversized entries are skipped; Teamagent needs explicit unavailable-entry results when the caller required a skill. Tool disclosure records the tools exposed by read/pinned skills and resolves a disclosed implementation again at execution. The fixtures cover snapshot retention, pinning a newer version separately, disclosure disappearing after summarization, and preventing a child result from pinning skills in the parent. [Pin implementation](https://github.com/langchain-ai/deepagents/blob/220aff708682ad0883469a00531e5c4d958b47ec/libs/deepagents/deepagents/middleware/skills.py#L819-L914), [disclosure/execution](https://github.com/langchain-ai/deepagents/blob/220aff708682ad0883469a00531e5c4d958b47ec/libs/deepagents/deepagents/middleware/skills.py#L1258-L1427), [fixtures](https://github.com/langchain-ai/deepagents/blob/220aff708682ad0883469a00531e5c4d958b47ec/libs/deepagents/tests/unit_tests/middleware/test_pinned_skills.py#L122-L244).

This suggests versioned skill selections and per-turn disclosure evidence, with content hashes and trusted tool bindings added by the harness. A body snapshot is not an executable integrity check, and current disclosure is not a grant to broaden resource access.

## Memory, backends and delegation

Memory middleware loads configured source files once when its state lacks memory contents, skips missing files, rejects other download errors and inserts ordered content into the system message. Its optional prompt-cache marker follows the actual request model and only recognizes the specific Anthropic wrapper. Teamagent should retain declared source identity and test actual cache semantics per provider; this file-loading mechanism does not supply a source-version lineage, retrieval index or automatic invalidation. [Memory runtime](https://github.com/langchain-ai/deepagents/blob/220aff708682ad0883469a00531e5c4d958b47ec/libs/deepagents/deepagents/middleware/memory.py#L192-L416).

Composite storage uses longest-prefix routing with path-component boundaries. Shell execution always goes to the default execution-capable backend, not a file mount. Subagents distinguish isolated context from forks, validate unique names, apply the parent's effective summarized history to forks, exclude private/control fields from result merging and refuse recursive task delegation from a fork. Child results become structured output or the latest nonempty assistant text. Teamagent should use explicit state-transfer manifests and preserve result evidence independently from this final text.
