## Initial scoped source review — 2026-11-01

Reviewed commit `30096e49d298a2f981d73926de48aa77ffe4a313` (2026-10-29T13:29:17+01:00), the 191-path tree inventory, package metadata, complete history-import CLI/planner/common reader/API bodies and history-import tests. This is a scoped implementation review; other capture integrations, the hosted service and its account/privacy guarantees were not audited or executed.

The importer separates preview, explicit application and optional dream processing, records original session/role/time provenance, skips active or unreadable sessions and reconciles existing server memories before writing. Preview nevertheless performs authenticated session-ID lookups: it is content-write-free, not network-passive. Per-project destinations are resolved before upload. The CLI groups reconciliation by host plus `keyFingerprint`, but that getter exposes only the final four key characters despite an internal full-key cache scope; distinct credentials with the same suffix can collide in that grouping. Use an opaque collision-resistant credential-scope identity for reconciliation and cache keys. [CLI](https://github.com/midbrainai/midbrain-memory-mcp/blob/30096e49d298a2f981d73926de48aa77ffe4a313/shared/history-import/cli.mjs), [API](https://github.com/midbrainai/midbrain-memory-mcp/blob/30096e49d298a2f981d73926de48aa77ffe4a313/shared/midbrain-api.mjs).

Import IDs hash client/session/role/time rather than content; the planner explicitly notes that the server does not enforce their uniqueness. Listing failures skip a session rather than treating incomplete state as empty, but preflight deduplication is not atomic idempotency across concurrent importers or changed transcript content. Writes make one attempt and distinguish rejection, quota/rate limits and uncertain server/transport outcomes. The API labels HTML 403 responses as firewall-blocked; that inference is not independent proof that a write never reached a server. Preserve bounded HTTP diagnostics and reconcile uncertainty before resuming. [Planner](https://github.com/midbrainai/midbrain-memory-mcp/blob/30096e49d298a2f981d73926de48aa77ffe4a313/shared/history-import/plan.mjs), [write and listing classification](https://github.com/midbrainai/midbrain-memory-mcp/blob/30096e49d298a2f981d73926de48aa77ffe4a313/shared/midbrain-api.mjs#L406).

The session list caps pagination at 20 pages and fails on a missing items array; inspected fetches still lack explicit request deadlines/body byte limits and full item validation. Transcript JSON rows stream with corrupt-middle/torn-tail handling and cleanup, but no inspected decompression/line/session aggregate budget exists; the planner retains entries before its 100,000-code-unit text truncation. Resource admission must precede parsing and collection. The tests cover preview without POST, confirmation, per-directory destinations, live-capture reconciliation, duplicate client selection and no retry after uncertain writes; they were read, not run. [Reader](https://github.com/midbrainai/midbrain-memory-mcp/blob/30096e49d298a2f981d73926de48aa77ffe4a313/shared/history-import/readers/common.mjs), [tests](https://github.com/midbrainai/midbrain-memory-mcp/blob/30096e49d298a2f981d73926de48aa77ffe4a313/tests/history-import.test.mjs).

Architecture consequence: retain preview/network/write distinctions, explicit provenance, destination-bound reconciliation and uncertain-write receipts in memory imports. These client mechanisms do not establish server ACLs, provider-training exclusion, successful real imports or transactional deduplication.
