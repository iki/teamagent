The [evaluation runner](https://github.com/cosmicstack-labs/mercury-agent/blob/2bdcca50d102221d2ed21cdb1aeb5acacd110704/src/eval/runner.ts#L122-L173) substitutes recorded tool outputs when present but calls the real tool when absent. Its [construction](https://github.com/cosmicstack-labs/mercury-agent/blob/2bdcca50d102221d2ed21cdb1aeb5acacd110704/src/eval/runner.ts#L248-L302) disables configured live providers and uses scripted ones, yet enables auto-approval and defaults to fake timers that suppress watchdog/provider deadlines. Therefore this is not automatically a side-effect-free replay or evidence of real timeout behavior. Idle detection requires 25 event-loop ticks in an idle state rather than an authoritative turn receipt. The expectations mostly inspect text, counts and provider/tool labels; when no expectation object is supplied, the helper returns before checking script exhaustion. Preserve fixture/real-effect provenance and separate semantic acceptance, deadline behavior and authorization tests. No harness or upstream test ran.

The [Web interaction path](https://github.com/cosmicstack-labs/mercury-agent/blob/2bdcca50d102221d2ed21cdb1aeb5acacd110704/src/channels/web.ts#L143-L208) checks allowed values, one-shot consumption and a two-minute fallback. It binds the target only when a cloud handler exists; a normal SSE-targeted interaction is stored without that binding. The [fixture](https://github.com/cosmicstack-labs/mercury-agent/blob/2bdcca50d102221d2ed21cdb1aeb5acacd110704/src/channels/web.test.ts#L69-L105) demonstrates both unbound SSE resolution and cloud rejection of another request. HTTP authentication and decision-route ownership were not inspected, so this is an adapter scope difference rather than an established external exploit. The prompt is broadcast before the pending interaction is registered, leaving synchronous handler re-entry unable to resolve it. Register owned state before notifying observers and apply equivalent request/principal binding on each transport.

The [delivery path](https://github.com/cosmicstack-labs/mercury-agent/blob/2bdcca50d102221d2ed21cdb1aeb5acacd110704/src/channels/web.ts#L122-L141) retains a cloud terminal handler when it refuses delivery, but SSE enqueue errors are swallowed and no client acknowledgement exists. Client maps, stream accumulation and controller queues have no local bounds. Tool feedback includes argument/result excerpts without the terminal error redactor, so diagnostic projection needs its own confidentiality policy. The choice-timeout fixture with no interactive target resolves immediately and therefore does not exercise its timer despite advancing the fake clock. Adapt explicit delivery receipts and fixture coverage claims, not the test suite's durable-streaming label as proof of durable delivery.
