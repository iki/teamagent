## Decision models, fallback and budgets

The router chooses among uniquely named model candidates from the latest user text, using either a typed classifier or structured chat output. It records the selected name by reply ID, restores it on resumed work, and restores the original agent model in a finally block. Routing exceptions, refusals, unknown names and missing text retain the original model. The Jev adapter translates binary, choice and score questions to the TypeSafe SDK, preserves confidence/probabilities and token/time usage, and configures request timeout and retries. The router itself uses the selected name, without a confidence threshold or account/training policy check in this module. [Router](https://github.com/agentscope-ai/agentscope/blob/4acacb9ffb8c148a1f1e68263657a978bcb1e5a3/src/agentscope/middleware/_model_router.py), [Jev adapter](https://github.com/agentscope-ai/agentscope/blob/4acacb9ffb8c148a1f1e68263657a978bcb1e5a3/src/agentscope/classifier/_jev/_model.py), [resume/fallback fixtures](https://github.com/agentscope-ai/agentscope/blob/4acacb9ffb8c148a1f1e68263657a978bcb1e5a3/tests/middleware_model_router_test.py#L199-L378).

The reply budget accumulates weighted input/output tokens after model-call completion. Once exhausted it restricts subsequent tools and requests a final answer, allowing the structured-output tool when still owed. This is useful graceful termination, but it is not a pre-call cost reservation or hard currency ceiling. Teamagent should admit the classifier request itself and every possible fallback under the same account, route, privacy and cost constraints before exposing user content; a stable reply decision must still be invalidated when its evidence or authorization changes. [Budget logic](https://github.com/agentscope-ai/agentscope/blob/4acacb9ffb8c148a1f1e68263657a978bcb1e5a3/src/agentscope/middleware/_budget.py#L107-L233).

## Memory and skill selection

Agentic memory maintains a bounded MEMORY.md prompt view and launches reply-scoped asynchronous selection over Markdown-file headers. It filters returned filenames against the enumerated set, deduplicates and admits at most five files, then injects completed retrieval once and cancels unfinished retrieval at reply end. This is a useful small-manifest/selected-body pattern. However, the reviewed scanner reads each candidate file before truncating its header, caps the file list after scanning, uses modification time for ordering, and skips several read/retrieval failures. Its context bounds do not establish bounded ingestion I/O, immutable source versions or complete retrieval. [Memory runtime](https://github.com/agentscope-ai/agentscope/blob/4acacb9ffb8c148a1f1e68263657a978bcb1e5a3/src/agentscope/middleware/_longterm_memory/_agentic_memory/_middleware.py#L513-L803), [scanner](https://github.com/agentscope-ai/agentscope/blob/4acacb9ffb8c148a1f1e68263657a978bcb1e5a3/src/agentscope/middleware/_longterm_memory/_agentic_memory/_middleware.py#L897-L959).

The local skill loader recognizes UTF-8 BOMs, parses frontmatter, requires name/description, caches by modification time and loads discovered skills concurrently. Teamagent should retain the metadata-first idea while using content hashes, bounded enumeration/concurrency, explicit failed-entry reporting, compatibility evidence and separate executable-resource grants. A loaded skill or model-written memory is not a new authority source. [Skill loader](https://github.com/agentscope-ai/agentscope/blob/4acacb9ffb8c148a1f1e68263657a978bcb1e5a3/src/agentscope/skill/_local_loader.py).

## Channel identity and resource authority

Channel routing derives stable session IDs from channel, agent and configured chat/user scope. Resource policy independently represents owner/resource/permission references, defaults cross-owner access to none and requires a matching EDIT grant for cross-owner mutation. The corresponding fixture checks owner access and denial of unrelated resources. This separation is reusable: session identity and group conversation membership must not become retrieval or credential authority. The local workspace manager uses an agent-derived directory and TTL cache with cleanup outside its lock; that lifecycle abstraction is not an operating-system sandbox. [Channel router](https://github.com/agentscope-ai/agentscope/blob/4acacb9ffb8c148a1f1e68263657a978bcb1e5a3/src/agentscope/app/channel/_routing.py), [resource policy](https://github.com/agentscope-ai/agentscope/blob/4acacb9ffb8c148a1f1e68263657a978bcb1e5a3/src/agentscope/app/access/_policy.py), [policy fixtures](https://github.com/agentscope-ai/agentscope/blob/4acacb9ffb8c148a1f1e68263657a978bcb1e5a3/tests/resource_access_policy_test.py#L210-L273), [local lifecycle](https://github.com/agentscope-ai/agentscope/blob/4acacb9ffb8c148a1f1e68263657a978bcb1e5a3/src/agentscope/app/workspace_manager/_local_workspace_manager.py#L15-L138).
