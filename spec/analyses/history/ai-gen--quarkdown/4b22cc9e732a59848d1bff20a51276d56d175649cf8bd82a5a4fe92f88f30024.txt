PipelineOptions now accepts a host-provided package resolver and defaults to Unsupported; detached contexts use the same unsupported fallback. This establishes an extension seam, not evidence that arbitrary document imports are safely resolved. The new latest-version helper compares parsed semantic versions, ignores invalid names and may select a prerelease when it outranks older stable releases; fixtures explicitly demonstrate that policy. Preview startup classifies bind failures only before readiness, handles asynchronous engine errors through a coroutine handler and logs later errors normally. A loopback hostname constant is defined, but the inspected embeddedServer call passes only engine/port and does not pass that constant, so this file alone does not prove loopback-only binding. Stacked rendering now carries node style/width/height; page-format tests assert generated CSS for paged versus slide layouts, without demonstrating final browser/PDF pagination.
