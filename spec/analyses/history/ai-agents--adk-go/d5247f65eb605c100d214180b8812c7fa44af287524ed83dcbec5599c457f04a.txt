## 2026-10-28 scoped update review

Reviewed commit `19707a2660a8dd7b8ffb32837027253ed2f29dd1` (commit date `2026-10-27T13:06:04+01:00`). The original snapshot above remains historical evidence.

**Scope:** Complete in-memory credential-store and provider implementations; GCP cache-key construction, HTTP transport replay, consent response handler and the wider runner were not audited.

The [credential store](https://github.com/google/adk-go/blob/19707a2660a8dd7b8ffb32837027253ed2f29dd1/auth/store.go#L41-L150) keys on application, user and producer-defined slot and explicitly warns that ADK does not authenticate the first two fields. Its contract requires every credential-changing input to enter an unambiguous key and treats both keys and credentials as sensitive. The implementation uses a comparable struct key, requires nonzero expiry and applies a ten-second skew before serving a value. Teamagent must bind these fields to the authenticated principal and grant, rather than accepting caller-supplied identity as cache isolation.

The [in-memory implementation](https://github.com/google/adk-go/blob/19707a2660a8dd7b8ffb32837027253ed2f29dd1/auth/store.go#L160-L278) protects map operations with a mutex, but has no size cap and only sweeps on calls. It returns the same credential object, placing immutability/concurrent-use obligations on producers. Delete removes the current entry without fencing an in-flight retrieval that may write it back; the contract documents this revocation race. Teamagent needs credential generations or equivalent conditional publication, bounded retention/admission and an explicit distinction between local cache invalidation and issuer revocation.

The [lazy provider](https://github.com/google/adk-go/blob/19707a2660a8dd7b8ffb32837027253ed2f29dd1/auth/providers.go#L226-L291) shares one initialization attempt and lets each caller stop waiting on its own context. A timer cancels the detached initializer's context, but clearing the in-flight attempt and notifying waiters still occurs only after init returns; a noncooperative initializer can outlive the advertised bound. The consent error deliberately keeps its URL out of Error(), yet exported fields can still be serialized, so error-string redaction is not a complete confidentiality boundary. No credential discovery, token request, upstream fixture or network replay was executed.

The upload path records its own timeout cause separately from an inherited caller deadline, measures stall time after a concurrency slot is obtained, and pauses later uploads for a shared cooldown. Failed uploads are retained for a later batch only under the explicit caller-cut-short/defer conditions; successful non-GCS locations are not treated as retained failures. For Teamagent, preserve phase-specific failure causes and explicit ownership of deferred work. The semaphore acquisition and wait group still depend on the offloader returning: a context deadline is not proof that a non-cooperative upload has stopped. These telemetry retry rules must not be transferred to ambiguous billable or enrollment operations. New model support and terminal trace reporting are outside this review.
