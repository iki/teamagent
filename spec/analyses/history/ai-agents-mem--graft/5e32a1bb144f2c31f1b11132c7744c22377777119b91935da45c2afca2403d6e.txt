Extraction cache files now include a stamp derived from sorted sibling graph-module names/content plus package version, allowing multiple installed versions to retain separate memos; pruning keeps two newest matching sidecars. Unknown identity disables memo use, while a package-version-only fallback is explicitly weaker for local edits. Cache reads check version, extractor and files-object shape but do not deeply validate cached nodes/edges or bound decoded file size, so disposable cache integrity is still a host boundary. Windows npm-style .cmd launch extracts the JavaScript entry and starts it with a selected executable directly, stripping NODE_OPTIONS case-insensitively instead of invoking a command shell. This special treatment applies only to recognized Windows shims; other commands inherit the environment. LSP requests resolve null on timeout/error, which becomes empty call edges, without cancelling the underlying request. The HTTP surface validates a bounded webhook body and queues a child-process review, but publishes private-page bearer tokens in query strings.
