# Open Notebook

Source: [Open Notebook](https://github.com/lfnovo/open-notebook) · [memory](../../memory.md), [agents](../../agents.md), [models](../../models.md), [import and generation](../../import-generation.md), [channels](../../channels.md), [decisions](../../decisions.md), [evolution](../../evolution.md), [media processing](../../media-processing.md), [security](../../security.md).

Open Notebook is a notebook-oriented research application with a Python API, persistent source and note records, retrieval, model-mediated answers, and background media generation. Its useful reference patterns are explicit processing state, retrieval-scope propagation and failure classification. Its accepted single-user posture must remain visible when considering a team harness.

## Ingestion, retrieval and provenance

The [source API](https://github.com/lfnovo/open-notebook/blob/a0f6f3081ae06328f0a451b3a3ef2959ca25721d/api/routers/sources.py#L427-L565) validates link/upload/text inputs, restricts supplied file paths to the upload root, records the source asset before queuing work, associates notebooks immediately and returns a command reference with a queued status. The [source graph](https://github.com/lfnovo/open-notebook/blob/a0f6f3081ae06328f0a451b3a3ef2959ca25721d/open_notebook/graphs/source.py) delegates extraction to content-core, retains the input URL/file path separately from extraction output, preserves a user-assigned title, then optionally submits embedding and transformations. Extractor errors are typed separately from genuinely empty text. Missing optional extraction runtimes fall back to the automatic engine chain with a warning; selected-engine identity alone is therefore insufficient evidence of which service processed content.

The [embedding command](https://github.com/lfnovo/open-notebook/blob/a0f6f3081ae06328f0a451b3a3ef2959ca25721d/commands/embedding_commands.py#L313-L430) chooses content-aware chunks, checks one embedding per chunk, stores their order/source relationship and removes partial inserts after a batch failure. Its [fixture](https://github.com/lfnovo/open-notebook/blob/a0f6f3081ae06328f0a451b3a3ef2959ca25721d/tests/test_embed_source_partial_cleanup.py) checks source-scoped cleanup, preservation of unrelated rows and retention of the original error if cleanup also fails. This is useful completeness handling, but deleting prior embeddings before replacement is not an atomic version switch. The reviewed `Asset`/`Source` fields and graph establish source/job identity, not a content-addressed immutable version chain or refresh-validator contract.

The [search boundary](https://github.com/lfnovo/open-notebook/blob/a0f6f3081ae06328f0a451b3a3ef2959ca25721d/api/routers/search.py) resolves notebook scope before model lookup; [domain functions](https://github.com/lfnovo/open-notebook/blob/a0f6f3081ae06328f0a451b3a3ef2959ca25721d/open_notebook/domain/notebook.py#L775-L929) validate record types/existence, bind scope as parameters, preserve it through text-to-vector fallback and deterministically sort vector results. An empty scope intentionally means global search. Database failure remains distinct from a missing notebook or zero results. [Search fixtures](https://github.com/lfnovo/open-notebook/blob/a0f6f3081ae06328f0a451b3a3ef2959ca25721d/tests/test_search_api.py#L202-L351) cover malformed, unknown and bounded scopes and validation ordering; the database functions themselves were not audited.

**Teamagent implication (inference):** Carry immutable source-version identity and explicit completeness through extraction, indexing and generated artifacts; publish an index only after complete validation. Static articles retain their original creation/import evidence. Any refresh remains an explicit policy with validators, independent of a retry button or automatic extractor fallback. Retrieval fallback must retain principal, scope and data-policy constraints and disclose changed processing routes.

## Context and model decisions

The [context builder](https://github.com/lfnovo/open-notebook/blob/a0f6f3081ae06328f0a451b3a3ef2959ca25721d/open_notebook/utils/context_builder.py) counts the same rendered Markdown it supplies to source chat, including identifiers, headings, insights and the truncation notice. It uses a token-prefix search with a bounded extra validation window for non-monotonic tokenization, reserves a limited insight share for large documents and reports truncation/omission. The offline word-count fallback is an estimate, not an exact provider-token guarantee. Notebook context can skip unavailable records; that path should not be mistaken for complete evidence coverage.

The [Ask graph](https://github.com/lfnovo/open-notebook/blob/a0f6f3081ae06328f0a451b3a3ef2959ca25721d/open_notebook/graphs/ask.py) separates strategy, per-search answer and final synthesis models, forwards notebook scope into every search, discards blank search terms and rejects an unusable strategy or empty final response. The shared 8,192-token output budget is explicit. Its suggestion of up to five searches is a schema description, without a list-length validator in this module; model-produced fan-out still needs a deterministic admission bound.

The [model manager](https://github.com/lfnovo/open-notebook/blob/a0f6f3081ae06328f0a451b3a3ef2959ca25721d/open_notebook/ai/models.py) distinguishes language, embedding, STT and TTS models, resolves per-model credentials and revalidates configured URLs before constructing provider clients. However, [language-model provisioning](https://github.com/lfnovo/open-notebook/blob/a0f6f3081ae06328f0a451b3a3ef2959ca25721d/open_notebook/ai/provision.py) selects the large-context default above 105,000 input tokens before honoring an explicit model ID. Credential load failure can also fall back to environment configuration. No account/operation training-exclusion gate was found in these reviewed selection paths.

**Teamagent implication (inference):** Keep routing budgets and fallback explanations, but apply deterministic account, route, training, consent and cost gates before ranking or content upload. Explicit backend/model selection cannot silently become another account or model when context grows or credentials fail. Bound model-proposed search count and concurrent work separately from output-token budgets, and expose estimates and omitted context honestly.

## Channel authority, credentials and network boundaries

The accepted [single-user decision](https://github.com/lfnovo/open-notebook/blob/a0f6f3081ae06328f0a451b3a3ef2959ca25721d/docs/7-DEVELOPMENT/decisions/PDR-001-single-user-first.md) explicitly defers multi-user support. The [authentication middleware](https://github.com/lfnovo/open-notebook/blob/a0f6f3081ae06328f0a451b3a3ef2959ca25721d/api/auth.py) compares a shared bearer password in constant time, exempts designated public paths/preflight requests and disables authentication when no password is configured. [Fixtures](https://github.com/lfnovo/open-notebook/blob/a0f6f3081ae06328f0a451b3a3ef2959ca25721d/tests/test_auth.py) include this unset-password behavior and non-ASCII credentials. Notebook retrieval scope is not proof of tenant authorization. Explicit context selections load records by ID in the reviewed builder; a team deployment would need its own authenticated membership checks.

The [request-size middleware](https://github.com/lfnovo/open-notebook/blob/a0f6f3081ae06328f0a451b3a3ef2959ca25721d/api/middleware.py) enforces both declared and streamed body bytes, with a configurable 100 MiB default. The [upload helper](https://github.com/lfnovo/open-notebook/blob/a0f6f3081ae06328f0a451b3a3ef2959ca25721d/api/routers/sources.py#L117-L183) atomically reserves a candidate filename and moves the subsequent filesystem write off the event loop; the upload is still read into memory in this path. This is not evidence of bounded-memory streaming or protection against every filesystem race.

The [URL utilities](https://github.com/lfnovo/open-notebook/blob/a0f6f3081ae06328f0a451b3a3ef2959ca25721d/open_notebook/utils/url_validation.py) deliberately allow private/localhost services, block link-local and named metadata addresses, and offer a separate DNS-pinned target helper. Ordinary validation alone is not connection-time pinning, and source ingestion delegates its actual fetch to another package. The [credential service](https://github.com/lfnovo/open-notebook/blob/a0f6f3081ae06328f0a451b3a3ef2959ca25721d/api/credentials_service.py#L214-L282) separates configuration status from an explicit connection test. Configuration presence is not authentication or provider-policy verification. The [legacy key provider](https://github.com/lfnovo/open-notebook/blob/a0f6f3081ae06328f0a451b3a3ef2959ca25721d/open_notebook/ai/key_provider.py) can copy stored keys into process environment and warns about stale keys; this is not request-isolated credential handling.

**Teamagent implication (inference):** Preserve distinct local-service and public-import network policies, per-request credential authority, passive status and active diagnostics. A notebook or channel label never grants resource authority. Private-network access and provider sharing policies require independent explicit evidence.

## Background work, recovery and media

The [source worker](https://github.com/lfnovo/open-notebook/blob/a0f6f3081ae06328f0a451b3a3ef2959ca25721d/commands/source_commands.py) distinguishes permanent missing-record, configuration, context-limit and incomplete-generation errors from transient failures. Its source-processing retry budget is fifteen attempts with exponential jitter; transformations have five. Successful extraction reports embedding as submitted rather than claiming completed chunks. [Deletion fixtures](https://github.com/lfnovo/open-notebook/blob/a0f6f3081ae06328f0a451b3a3ef2959ca25721d/tests/test_source_deleted_before_processing.py), [context-limit fixtures](https://github.com/lfnovo/open-notebook/blob/a0f6f3081ae06328f0a451b3a3ef2959ca25721d/tests/test_context_length_no_retry.py) and [retry-visibility fixtures](https://github.com/lfnovo/open-notebook/blob/a0f6f3081ae06328f0a451b3a3ef2959ca25721d/tests/test_background_retry_visibility.py) provide concrete failure cases. They were inspected, not executed. Retrying an entire graph is not evidence that each provider effect is idempotent.

STT is a configured extraction capability in the source graph. The [podcast command](https://github.com/lfnovo/open-notebook/blob/a0f6f3081ae06328f0a451b3a3ef2959ca25721d/commands/podcast_commands.py) separately resolves outline, transcript and TTS models, validates selected profiles, creates a UUID-named output directory and uses a single command attempt. It saves transcript/outline before surfacing an in-band audio-combination error, preserving useful partial results. The [service](https://github.com/lfnovo/open-notebook/blob/a0f6f3081ae06328f0a451b3a3ef2959ca25721d/api/podcast_service.py) exposes job status; its fallback to a notebook-ID string after context-loading failure is not faithful source-content recovery. Voice cloning, measured audio identity, training exclusions, durable provider idempotency and completed-artifact recovery were not established by this scope.

**Teamagent implication (inference):** Preserve stage results and terminal error causes, distinguish submitted/completed/published states, and reconcile uncertain remote work before retrying. A failed audio assembly should retain approved transcript and generated references rather than purchase another generation automatically. Never substitute a record identifier for unavailable source content. Batch status queries can reduce overhead, but unknown status must remain unknown.

## Scope and adoption limits

The inspected [project metadata](https://github.com/lfnovo/open-notebook/blob/a0f6f3081ae06328f0a451b3a3ef2959ca25721d/pyproject.toml) identifies the FastAPI/Pydantic, LangGraph, SurrealDB, content-core, Esperanto and podcast-creator boundaries. The repository carries an [MIT license](https://github.com/lfnovo/open-notebook/blob/a0f6f3081ae06328f0a451b3a3ef2959ca25721d/LICENSE); that does not settle dependency, model, provider-service or voice rights. This scoped review does not benchmark throughput, audit the frontend/deployment, establish operating-system network isolation, validate the complete credential-storage implementation, or test the delegated extraction/generation packages. It contributes design evidence and targeted regression ideas rather than an implementation or security certification for Teamagent.
