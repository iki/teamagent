## Change review - 2026-10-28

**UTC query pushdown and typed payload serialization improve context correctness without total-context bounds.** Reviewed commit `32a4710010a88cc4fd765574e8c6c00200f5d754` (commit date `2026-10-26T00:07:13+01:00`). Compared with `006923b101178ac93d1360042adfb0d119de4540`; the complete Git comparison contains 360 changed paths.

TimeWindowContextProvider computes an aware UTC cutoff and pushes it into the store filter instead of fetching all artifacts then comparing against a naive local timestamp. Its base call path still applies identity visibility and exclusions after retrieval; fixtures cover recent/old artifacts with real memory and SQLite stores plus a deterministic agent engine. The query retains limit=-1, so a busy window can still return unbounded history before visibility filtering. SQLite now uses Pydantic's JSON-compatible conversion for datetime/date/UUID/Decimal payloads and reconstructs typed models; a round-trip fixture checks equality. Consumption lookup gains indexed implementations, while generic fallback scans 100-item pages without a global budget. The SQLite worker is now daemonized so an unclosed store does not keep process exit alive; fixtures check exit and explicit shutdown/reopen, but daemon termination is not proof of drained pending writes or crash durability.
