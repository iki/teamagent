Hybrid retrieval runs synchronous BM25 on a blocking worker alongside vector embedding/search, applies source-document filtering inside both recall channels, and exposes RRF score plus per-channel ranks. Scored pages request a consistent 100-candidate depth per channel and report vector_used; model absence, embedding failure and empty embedding responses all become the same unavailable-vector state, while database vector errors still propagate. Each page recomputes retrieval, so fixed depth alone does not provide a snapshot across concurrent updates. The module explicitly states that current-only Tantivy indexing cannot recall superseded historical chunks; as-of filtering of returned candidates does not recover missing lexical history. The historical fixture exercises preserved vectors/tombstones against a database but returns success without assertions when no test database URL exists. SessionOrToken retains a personal-token identity and narrowing helpers, while ordinary AuthUser remains JWT-only; helper use and underlying role checks are still route responsibilities.
