> Benchmark for evaluating LLM instruction conflict resolution across arbitrarily many privilege levels. LLM agents receive instructions from many sources — system messages, user prompts, tool outputs, skill files, and other agents — each carrying different levels of trust and authority. Current instruction hierarchy (IH) implementations assume a fixed, small set of privilege levels (typically fewer than five) defined by rigid role labels (e.g., `system > user`), creating a **fixed- and few-tier bottleneck** insufficient for real-world agentic se
