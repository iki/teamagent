## Initial source review - 2026-10-28

**Transfer-state serialization and generated database models are useful adapter references, not execution guarantees.** Reviewed commit `6ea903e33904f479bc7cd626e8d2d6320dd84fa2` (commit date `2026-10-28T01:14:18+08:00`). The enumerated snapshot contains 7928 tracked paths.

This initial inspection covers DBX's desktop transfer-task store, deterministic model renderers and MCP binary launcher. The transfer store rejects unknown library versions and invalid top-level entries before allowing queued mutations, retries a failed initialization, serializes public mutations within one store instance and rolls back optimistic state when whole-library persistence fails. It deliberately resets dropTargetConfirmed on load. Nested data is still normalized by partial casts and coercion: unknown object-kind keys survive, several enum-like values are passed through, and any positive numeric batch size is accepted. The queue has no local admission cap or deadline and does not establish cross-process compare-and-swap persistence.

The model registry emits 15 language/schema targets and deduplicates normalized names, preserving original field-name mappings explicitly for Go/Rust. It maps TypeScript integer columns to number, which does not preserve every database integer's precision; generated shapes do not reproduce all database constraints. Fixtures check selected emitted strings and registry membership, not compilation and round-trip validity across every target. The MCP launcher selects an installed platform package or an explicit executable override, inherits environment/stdio and forwards signals. --verify-platform checks the platform table only; it does not resolve the binary or verify its integrity or execution.

## Follow-up change review — 2026-10-28

**Comparison queries inherit explicit connection timeout settings.** Reviewed commit `a382bd25a4a8eb9371d1330cd251810743e9a1e9` (commit date `2026-10-28T17:46:30+08:00`), compared with `6ea903e33904f479bc7cd626e8d2d6320dd84fa2`. The complete no-rename Git path inventory contains 150 changed paths.

The new compare-query option helper reads the connection's effective timeout while preserving max_rows. The fixture checks explicit zero as unlimited, a configured 120-second value and a missing connection as None for the historical default. This removes a hidden default from comparison operations but does not supply a safe universal task deadline.
