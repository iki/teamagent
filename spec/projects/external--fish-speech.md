# Fish Speech and Fish Audio service review

Reviewed: 2026-10-25. Source: [fishaudio/fish-speech](https://github.com/fishaudio/fish-speech), commit [541566932abbaebcb0a40e562a1f846738383f38](https://github.com/fishaudio/fish-speech/commit/541566932abbaebcb0a40e562a1f846738383f38), committed 2026-10-14. Scope: pinned schema, server authentication, README/license plus current hosted contracts; no model execution. Related: [media processing](../media-processing.md), [generation](../generation.md), [import/generation](../import-generation.md).

Hosted synthesis is `POST https://api.fish.audio/v1/tts`, Bearer authentication, exact `model` header and an explicit output format. JSON supports a persistent `reference_id`. The current hosted OpenAPI explicitly requires MessagePack with raw binary `references[].audio` and matching `text` for inline conditioning. Unknown model headers fall back upstream to `s2.1-pro`; reject typos before dispatch. [TTS reference](https://docs.fish.audio/api-reference/endpoint/openapi-v1/text-to-speech), [OpenAPI](https://docs.fish.audio/api-reference/openapi.json).

The local implementation has a different contract: [schema lines48–105](https://github.com/fishaudio/fish-speech/blob/541566932abbaebcb0a40e562a1f846738383f38/fish_speech/utils/schema.py#L48-L105) attempts base64 decoding, accepts local streaming controls and documents an ignored repetition penalty. Those facts cannot prove hosted JSON base64 support. The [server authentication](https://github.com/fishaudio/fish-speech/blob/541566932abbaebcb0a40e562a1f846738383f38/tools/api_server.py#L30-L53) is conditional on a configured key. A deployed local service therefore needs explicit authentication/network policy; merely copying its launch command is insufficient.

Persistent enrollment uses multipart `POST /model`: type `tts`, title, `train_mode: fast`, repeated voice files, explicit private visibility and optional matching texts. Preserve `_id` and state; do not equate creation with trained readiness. The generated JSON example conflicts with the reference's explicit multipart instruction; follow the latter. [Create-model contract](https://docs.fish.audio/api-reference/endpoint/model/create-model).

S2.1-Pro is a hosted model; it is not the downloadable S2-Pro checkpoint. Drama 3 and S2-Pro share a local server but differ in architecture and capability. The pinned [README](https://github.com/fishaudio/fish-speech/blob/541566932abbaebcb0a40e562a1f846738383f38/README.md) describes Drama 3 as 35B total/3B active and S2-Pro as 4B. This does not establish local memory requirements or measured throughput. Drama editing capability in a model announcement does not imply a generally available editing API.

The pinned [Community License](https://github.com/fishaudio/fish-speech/blob/541566932abbaebcb0a40e562a1f846738383f38/LICENSE) permits limited commercial use below its aggregate revenue threshold but separately restricts hosted services, with stated exceptions including a product's own assistant replies. S2-Pro weights retain a separate research license. Record code, checkpoint, codec and intended deployment independently; do not label all variants permissive open source. Preserve consent/legal-right evidence and attribution requirements. These are observed terms, not a legal determination for a deployment.

Adoption: implement hosted TTS plus private enrollment first; evaluate local Drama/S2 separately after provisioning and license review. Pricing uses UTF-8 bytes: S2.1-Pro $15/M, Drama 3 $50/M list and $10/M through 2026-11-12 17:00 UTC. [Billing](https://docs.fish.audio/developer-guide/models-pricing/pricing-and-rate-limits). Never use Unicode character count as its billing estimator.

The [official Python SDK](https://github.com/fishaudio/fish-audio-python) has a separate [scoped review](external--fish-audio-python.md). Its types do not establish hosted PCM byte order; the local [server converter](https://github.com/fishaudio/fish-speech/blob/541566932abbaebcb0a40e562a1f846738383f38/tools/server/inference.py#L37-L46) uses native-endian NumPy int16. Prefer container output until the hosted raw-PCM contract is verified.

## Training policy review 2026-10-25

The [standard terms](https://fish.audio/terms/) permit model improvement. The [Customer Agreement](https://fish.audio/enterprise-terms/) covers specified acceptance and paid-account events; its title does not limit it to separately signed enterprise contracts. Eligible ZDR processing excludes training prospectively, subject to model/feature, retained-content and third-party exceptions. A paid account or private model is insufficient evidence by itself.

The harness requires exact account, credential, host, model and operation coverage for an exclusion. A synthesis ZDR record cannot authorize persistent clone creation: the latter requires operation-specific evidence. Unknown hosting terms remain blocked. See the [training boundary](../media-training.md) and [policy ledger](../analyses/media-training-reviews.md).
