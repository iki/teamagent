## Category assessment

Curated procedural bundles, reference catalogs, domain-specific workflows, and trace-derived learning recipes.

Curate narrowly useful bundles instead of enabling an entire library. Superpowers supplies planning/debugging procedures; Everything Claude Code contributes scoped atomic lessons; Trail of Bits supplies opt-in security workflows; Context Hub offers versioned references. Preserve originals and compile evaluated overlays for each target harness and model.

Documentation instructions can exceed a host's real capabilities, hook reliability varies, and confidence in an extracted lesson is not validation. Screened bundles remain candidates; selection should depend on trigger negatives and measured marginal task benefit rather than reputation alone.
