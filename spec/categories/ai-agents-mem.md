## Category assessment

Persistent episodes, semantic claims, temporal graphs, code intelligence, compiled knowledge, and task-context assembly.

Own immutable evidence and rebuildable indexes independently of any memory vendor. Graphiti contributes temporal relation semantics; Hindsight separates recall from reflection; OpenViking illustrates bounded context assembly. GitNexus and MentisDB add code-aware navigation and attributed record patterns. Start with simpler retrieval before paying for graph construction or repeated reflection.

Memory products solve different scopes. Hash chains do not establish truth, generated summaries remain derived claims, and design-only wiki material is not an implemented service. Permissions, freshness, deletion, and outcome evaluation remain harness responsibilities.
