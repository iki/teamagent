## Category assessment

Generated component interfaces, creative agent workspaces, editable compositions, and deterministic rendering tools.

Separate generated artifact surfaces from the deterministic application shell. A2UI and json-render offer catalog-constrained UI approaches; choose one initially. OpenDesign provides agent/media readiness patterns. HyperFrames supplies an editable composition-to-video path that belongs behind asynchronous artifact jobs and isolated rendering workers.

Schema-valid UI still needs authorized actions and safe URLs; A2UI's inspected validator requires explicit strict configuration. Renderers are not foundation media models, and cross-platform parity, accessibility, visual quality, and performance were not measured.
